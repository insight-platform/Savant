NvInfer Unit Overview and Common Configuration
==============================================

In Savant, DeepStream NvInfer is used to run inference on models prepared for Nvidia DeepStream. The framework supports four types of inference units:

- :doc:`30_dm` - detector unit;
- :doc:`40_cm` - classifier unit;
- :doc:`43_am` - attribute model unit;
- :doc:`53_complexm` - complex model unit.

Each of these units is configured differently. In this section, we describe common parameters for all units.
